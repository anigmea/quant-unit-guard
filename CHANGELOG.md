# Changelog

## 0.1.0 (unreleased)

- Explicit daily/annual and percent/decimal labels.
- Volatility, log-return mean and covariance conversions with caller-supplied frequency.
- Square/symmetry/PSD covariance validation including singular matrices.
- Volatility/covariance unit and diagonal contract checks.
- Offline JSON CLI and regression tests; no runtime dependencies.

Not a calendar engine, exact-money library or proof that a strategy is correct.
